## Review fixes

Representation hashing now streams the existing length-prefixed encoding through SHA-256 with fixed 1 KiB scratch storage. Golden hashes cover empty input, binary/Unicode data, sorted relation metadata, ignored non-relation metadata, and fields spanning multiple chunks. Identity tests retain identical body and relation metadata, prime the representation cache, then change or remove only the identity field under test. They verify revision acceptance, conflict preservation, and full reconciliation.

Measurement also exposed unnecessary 101-slot page-key allocation for one-neighbor queries. Capacity now follows available adjacency. Expected-edge storage is preallocated during fingerprint installation. The PR title now uses allowed `client` scope. Blanket docstring coverage was declined under the repository's terse-comment rule.

## Feature-exercising token replay

`TestNeighborhoodBinaryReplay` runs both production MCP binaries against one authenticated read-only synthetic server with separate empty HOME/graph caches. It checks cold and repeated outgoing dependency exploration, then prepares the same graph by crawling and checks incoming dependencies, supersession, plain-link pagination with continuation, and backlinks. Assertions require actual relations and continuation, not merely successful empty responses.

Results are byte-identical across both binaries, including the complete sorted tool catalog. Seven checked tool responses total **1,927 o200k_base tokens per arm**. Serialized tool definitions are also identical at **2,843 tokens**. Crawl preparation output is excluded from these seven response counts; this is a controlled replay, not a complete model episode or provider-schema accounting.

No new paid model cohort ran during comment fixes. The replay demonstrates output-token neutrality for exercised graph paths, not lower total model tokens per correct answer. The earlier paid results remain unchanged. The required combined performance-and-token gate remains unmet.

For mechanical before results, map main's canonical absolute paths for `client/graphstore/graph_baseline_test.go` and `tools/internal/broker/graph_baseline_test.go` to the reviewed files in a Go overlay.
